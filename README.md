# 🔥 Flame Stats - Bot de Estatísticas para Discord

## 🌟 Visão Geral

O **Flame Stats** foi um bot de Discord criado em **Python** dedicado a interagir com a API pública do FlameMC (`api.flamemc.com.br`).

Seu principal objetivo era fornecer aos jogadores e comunidades do Discord acesso rápido e formatado (em embeds) às estatísticas dos jogadores e aos rankings dos principais minigames.

---

## 💡 Funcionalidades Principais

Comandos que estavam disponíveis nesta versão do bot:

### 1. Estatísticas e Status

| Comando | Descrição |
| :--- | :--- |
| `/info` | Verifica e exibe as estatísticas completas de um jogador específico (kills, deaths, vitórias, etc.). |
| `/status` | Verifica o estado atual do servidor FlameMC (se está online/offline). |
| `/convite` | Fornecia o link de convite do bot. |

### 2. Leaderboards (Rankings)

Comandos para exibir os rankings dos minigames com filtros semanais, mensais e totais.

| Minigame | Comandos | Filtros Disponíveis |
| :--- | :--- | :--- |
| **ArenaPvP** | `/arena` | semanal, mensal, total |
| **Clan x Clan** | `/cxc` | semanal, mensal, total |
| **FlameLeague** | `/flameleague` | semanal, mensal, total |
| **FPS** | `/fps` | semanal, mensal, total |
| **HG** | `/hg` | semanal, mensal, total |

### 3. Moderação e Gerenciamento

Comandos restritos à moderação do servidor para controlar onde o bot era utilizado.

| Comando | Descrição |
| :--- | :--- |
| `/canais adicionar` | Adicionava um canal específico onde o uso de comandos do bot era permitido. |
| `/canais remover` | Removia um canal da lista de permissão de comandos. |
| `/canais lista` | Exibia a lista de canais configurados onde o bot podia ser usado. |

---

## 🛠️ Tecnologias

* **Linguagem:** Python
* **Framework:** Discord.py
* **Hospedagem:** **DisCloud** (Plataforma gratuita utilizada para manter o bot rodando 24/7).
* **Assistência de IA:** Google Gemini (Utilizado como ferramenta de apoio no desenvolvimento e otimização do projeto).
* **Integração:** Requisição de API (HTTP Requests) para a API pública do FlameMC.
